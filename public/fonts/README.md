# Fonty napisów

Wszystkie fonty w tym katalogu są udostępnione na licencji SIL Open Font License 1.1
(treść licencji: `LICENSE-OFL.txt`). Źródła: Google Fonts (`github.com/google/fonts`)
oraz repozytorium Montserrat (`github.com/JulietaUla/Montserrat`).

Te same pliki są używane:
- w przeglądarce (podgląd napisów w edytorze, `@font-face` w `globals.css`),
- przez libass/FFmpeg podczas wypalania napisów w MP4 (`fontsdir`).

Dzięki temu podgląd i finalny render korzystają z identycznych krojów.
